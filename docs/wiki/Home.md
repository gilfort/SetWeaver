# SetWeaver Wiki

**SetWeaver** is a NeoForge mod that lets modpack makers define **armor set bonuses**: mob effects and attribute
modifiers that activate when a player wears several pieces of a set. A set is any item tag, so armor from every mod
works. Bonuses can be limited to player roles and levels. Everything can be edited in-game.

## Overview

| Feature | Description |
|---|---|
| **In-game editor** | Create and edit sets without touching JSON |
| **Tag-based sets** | A set applies to every item in an item tag |
| **Roles & levels** | Limit bonuses to player roles and levels |
| **Effects & attributes** | Mob effects and attribute modifiers per threshold (1–4 pieces) |
| **Attribute packages** | Collapse related attributes into one tooltip line |
| **Custom tags** | Create item tags in-game (world datapack) |
| **Several sets per item** | Shift + scroll pages through them in the tooltip |

## Requirements

- Installed on **server and client** (the client needs it for tooltips and the editor).
- Editing and the commands need **operator level 2**.
